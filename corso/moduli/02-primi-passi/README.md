## Argomenti
1. Scaricare ed eseguire un modello con `-hf` e la cache locale (`--cache-list`)
2. Chat interattiva, prompt di sistema (`-sys`), chat template
3. Parametri di generazione: temperatura, top-k, top-p, min-p, penalità, seed
4. Contesto (`-c`), predizione (`-n`), thread (`-t`)
5. Leggere i log: caricamento, backend, velocità di prompt processing e generazione
6. `llama completion` e differenze rispetto a cli

## Laboratori
- [Il primo modello](../../laboratori/lab-02-01-primo-modello/README.md): Scaricare un modello piccolo da Hugging Face, chattare, leggere i log e annotare token/s.
- [Esperimenti di campionamento](../../laboratori/lab-02-02-campionamento/README.md): Stesso prompt con parametri diversi e seed fisso: osservare e documentare gli effetti.
- [Chat template e prompt di sistema](../../laboratori/lab-02-03-chat-template/README.md): Confrontare lo stesso modello con template corretto/errato e prompt di sistema diversi.
