# P3: Agente con strumenti

> Moduli di riferimento: 04, 06, 08 · Stato: 🟡 traccia da dettagliare

## Descrizione
Un agente locale che usa strumenti (file, web, calcolo, API) tramite tool calling e output strutturato.

## Requisiti minimi
- Almeno 3 strumenti reali
- Gestione degli errori e dei limiti del modello
- Log delle decisioni dell'agente
- Confronto tra 2 modelli
