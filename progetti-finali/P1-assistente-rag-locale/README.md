## Descrizione
Un assistente che risponde su un archivio di documenti (PDF/Markdown) interamente in locale, citando le fonti.

## Requisiti minimi
- Server llama.cpp per chat ed embedding
- Indicizzazione e ricerca vettoriale
- Interfaccia web o CLI
- Valutazione su un set di domande con risposte attese
