## Griglia di valutazione
| Criterio | Peso |
|---|---|
| Funziona ed è riproducibile seguendo il README | 30% |
| Scelte tecniche motivate (modello, quantizzazione, parametri) con misure | 25% |
| Qualità del codice e della configurazione | 20% |
| Relazione e demo | 15% |
| Estensioni | 10% |
